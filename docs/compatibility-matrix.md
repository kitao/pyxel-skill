# Compatibility Matrix

Known current runtime pairings for `pyxel-skill`.

| pyxel-skill | pyxel-mcp | Pyxel | Python | Notes |
|---|---|---|---|---|
| 1.1.0 | >= 1.0.0 | >= 2.9.6 | >= 3.10 | Lean default loop plus optional strict mode. |

Register `pyxel-mcp` under the `pyxel` MCP namespace before the skill starts. Run `pyxel_info` first when debugging a host setup.
